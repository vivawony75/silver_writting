    📋 출석체크

    다른 기기(PC, 모바일) 실시간 연동 대기 중
    🔍 [파이어베이스 연결 진단] 버튼을 누르면 실시간 데이터베이스(RTDB) 연결 및 보안 규칙 상태를 확인합니다.

    ※ 다른 기기(스마트폰, 다른 PC)와 실시간 연동하려면 Google Firebase 무료 Realtime Database 주소를 입력하면 자동으로 모든 기기의 출석, 글, 사진, 질문이 실시간으로 합쳐집니다.

    📌 구글 파이어베이스 100% 실시간 연동을 위한 [규칙] 설정 가이드 필수 1회

    구글 파이어베이스는 새 데이터베이스 생성 시 보안을 위해 외부 읽기/쓰기가 잠겨(Permission Denied) 있습니다.
    아래 4단계를 따라 규칙을 true로 변경해 주셔야 스마트폰과 PC 간에 사진, 출석, 글, 질문이 실시간으로 저장되고 관리자 화면에 즉시 나타납니다.

    1
    파이어베이스 콘솔 [규칙(Rules)] 페이지 열기:
    🔗 내 파이어베이스 콘솔 규칙(Rules) 설정 바로가기 ↗
    2
    규칙 입력창의 기존 내용을 지우고 아래 5줄 코드로 교체: 
    {
  "rules": {
    ".read": true,
    ".write": true
  }
}
    3
    파이어베이스 화면 우측 상단의 파란색 [게시 (Publish)] 버튼 누르기
    4
    위의 [🧪 지금 연결 상태 진단하기] 버튼을 누르면 즉시 초록색으로 연동 성공이 확인되며 모든 데이터가 실시간으로 동기화됩니다!

    ※ 인터넷 클라우드 없이도 스마트폰에서 내보낸 파일을 관리자 PC에서 불러오면 모든 출석과 글을 즉시 합칠 수 있습니다.

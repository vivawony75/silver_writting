# 글 짓는 부엌

시니어(65세 이상)를 대상으로 한 학습 및 정보제공형 스크롤 웹사이트입니다.

---

## 1. 파일 구조

- `index.html`: 메인 웹페이지 구조 (출석체크, 베껴쓰기, 사이트 섹션)
- `style.css`: 시니어 맞춤형 큰 글씨 및 파스텔톤 녹색/파란색 보색 기반 어스톤 스타일시트
- `script.js`: 일자별 베껴쓰기 데이터 연동 및 매일 자정(0시) 자동 갱신 스크립트
- `data.csv`: A열 날짜별 B열 글귀가 저장된 원본 데이터 파일
- `.gitignore`: 깃(Git) 버전 관리 제외 파일 목록

---

## 2. 주요 기능 및 메뉴 구성

1. **상단 네비게이션**
   - **출석체크**: 구글 폼 링크(`https://forms.gle/BktvP7mZ7KpPWmLMA`) 연결
   - **베껴쓰기**: 페이지 내 베껴쓰기 섹션으로 부드러운 스크롤 이동
   - **사이트**: 페이지 내 사이트 섹션으로 부드러운 스크롤 이동

2. **출석체크**
   - 구글 설문지 바로가기 연결

3. **베껴쓰기**
   - 첨부된 데이터(`data.csv`) 기반 A열 날짜에 해당하는 B열 내용을 화면에 바로 표시
   - 매일 자정(0시)이 되면 화면 새로고침 없이 자동으로 해당 날짜 내용으로 갱신
   - 예: 2026-10-05 글귀 → 0시가 되면 2026-10-06 글귀로 자동 전환

4. **사이트**
   - **글쓰기**
     - 국립국어원 표준국어대사전 (`https://stdict.korean.go.kr/search/searchResult.do`) 및 검색창 바로 검색 기능
   - **글쓰기 관련 교육기관**
     - 경남정보대학교 디지털문예창작학과 (`https://writing.kit.ac.kr`)
     - 부산경상대학교 AI문예창작과 (`https://univ.bsks.ac.kr/department/writing`)

---

## 3. 디자인 특징

- **시니어 친화적 UI**: 65세 이상 어르신을 위해 선명하고 큼직한 글꼴 크기, 여유로운 줄 간격, 큼직한 버튼 터치 영역 적용
- **색상 팔레트**: 눈의 피로를 줄여주는 파스텔톤 어스톤(Earth-tone) 바탕 위에 녹색(쑥색)과 파란색(청자색) 보색 대비 적용

---

## 5. 깃허브(GitHub) 업로드 및 무료 호스팅(GitHub Pages) 방법

1. GitHub에서 새 저장소(New repository)를 생성합니다.
2. 바탕화면 `[복지기술과제]` 폴더 내의 파일들을 해당 저장소에 업로드(Push)합니다.
3. 저장소의 **Settings** -> **Pages** 탭으로 이동합니다.
4. **Branch**를 `main` (또는 `master`)으로 선택하고 저장(Save)하면 무료 웹사이트 주소가 생성됩니다.

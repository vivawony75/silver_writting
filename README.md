# 글 짓는 부엌

시니어(65세 이상)를 대상으로 한 학습 및 정보제공형 스크롤 웹사이트입니다.

---

## 1. 파일 구조

- `index.html`: 메인 웹페이지 구조 (출석체크, 베껴쓰기, 사이트 섹션)
- `style.css`: 시니어 맞춤형 큰 글씨 및 파스텔톤 녹색/파란색 보색 기반 어스톤 스타일시트
- `script.js`: 일자별 베껴쓰기 데이터 연동 및 매일 자정(0시) 자동 갱신 스크립트
- `data.csv`: A열 날짜별 B열 글귀가 저장된 원본 데이터 파일
- `.gitignore`: 깃(Git) 버전 관리 제외 파일 목록

---

## 2. 주요 기능 및 메뉴 구성

1. **상단 네비게이션 및 섹션별 제목 배너 디자인**
   - **원래 제목 기반 타이틀 배너 (Title Banner)**: 각 섹션의 원래 제목(`베껴쓰기`, `글쓰기`, `사이트`, `출석체크`, `회원 글 모음`)에 품격 있고 시인성이 높은 배너 디자인을 적용하였습니다.
     - `📖 베껴쓰기`: 싱그러운 자연 녹색 그라데이션 배너
     - `✍️ 글쓰기`: 차분하고 신뢰감 있는 코발트 블루 그라데이션 배너
     - `🌐 사이트`: 세련된 올리브 틸 그라데이션 배너
     - `📋 출석체크`: 중후하고 안정적인 차콜 슬레이트 그라데이션 배너
     - `📚 회원 글 모음`: 중후하고 안정적인 차콜 슬레이트 그라데이션 배너
   - **상단 메뉴 네비게이션 간소화**: 부가적인 배지 문구를 모두 제거하고 핵심 메뉴명(`베껴쓰기`, `글쓰기`, `사이트`, `출석체크`, `회원 글 모음`)만 깔끔하게 노출
   - **글 짓는 부엌 로고 크기 확대 및 폰트 안전 처리**:
     - 상단 메인 로고 폰트 크기 **38px(모바일 32px)** 유지
     - `a시네마M`체는 비영리라 하더라도 웹폰트 무단 배포가 금지된 저작권 서체이므로 로컬 안전 fallback(`font-family: 'a시네마M', ...`) 적용

2. **사용자 인증 (로그인 분홍색 전환 & 자동 출석체크)**
   - **로그인 시 분홍색 전환**: 상단 이름과 비밀번호를 입력하고 로그인하면 해당 영역이 산뜻한 분홍색으로 바뀌어 로그인 상태를 직관적으로 확인할 수 있으며, [로그아웃] 시 원래 색상으로 복원됩니다.
   - **자동 출석체크**: 상단에서 이름과 비밀번호(숫자 4자리)를 입력하고 [확인]을 누르면 당일 출석체크가 자동으로 완료되고 누적 횟수가 계산됩니다.

3. **다른 기기(PC, 모바일폰) 실시간 연동 및 관리자 열람 (예성원 / 8797)**
   - **크로스 디바이스 연동**: 사용자가 스마트폰이나 다른 PC에서 로그인하여 출석체크를 하거나 글을 작성하더라도, 관리자(`예성원` / `8797`)가 관리자 화면에서 모두 실시간으로 열람할 수 있습니다.
   - **클라우드 실시간 동기화 바**:
     - `[🔄 지금 동기화 새로고침]`: 다른 기기(모바일폰 등)에서 실시간으로 올라온 출석 및 글 데이터를 즉시 불러옵니다.
     - `[⚙️ 클라우드 DB 설정]`: Google Firebase 무료 Realtime Database 주소 또는 REST API 엔드포인트를 손쉽게 등록·변경할 수 있습니다.
     - `[💾 백업/복원]`: 네트워크 연결에 제약이 있는 환경에서도 전체 데이터를 단일 `.json` 파일로 내보내거나 가져와 기기 간 데이터를 100% 온전히 합칠 수 있습니다.
   - **출석체크 (회색 영역)**: `날짜`, `이름`, `비번`, `누적 출석 횟수` 순서의 엑셀 양식 테이블, 행별 [삭제] 버튼, **정확히 5줄 노출 후 초과 시 스크롤**, [출석부 다운로드 (.csv)] 지원
   - **회원 글 모음 (출석체크 아래 회색 영역)**: **정확히 5줄 노출 후 초과 시 스크롤**, **한 문서에 모든 글을 모아서 내려받는 기능**([회원 글 모음 다운로드 (.txt)], [회원 글 모음 다운로드 (.csv)]) 지원
   - **넓어진 스크롤바 & 짙은 짙은 갈색 스크롤 막대**: 어르신들의 조작 편의를 위해 모든 스크롤바 폭을 **16px**로 넉넉하게 확장하고, 스크롤 막대를 눈에 잘 띄는 **짙은 짙은 갈색 (`#381E0D`)**으로 통일 설정하였습니다.

4. **베껴쓰기**
   - 첨부된 데이터(`data.csv`) 기반 A열 날짜에 해당하는 B열 내용을 화면에 바로 표시
   - 매일 자정(0시)이 되면 화면 새로고침 없이 자동으로 해당 날짜 내용으로 갱신
   - 예: 2026-10-06 글귀 → 0시가 되면 2026-10-07 글귀로 자동 전환

5. **글쓰기**
   - 상단에서 이름과 비밀번호(숫자 4자리)를 입력한 사용자만 글쓰기 가능
   - **제목란과 내용란 분리**: 제목과 내용을 각각 입력하여 [글 등록] 가능
   - **내가 쓴 글 5줄 리스트**: 본인이 쓴 글 제목이 5줄 리스트로 표시되며, 5줄을 초과할 경우 내부 스크롤 형식으로 깔끔하게 5줄만 노출
   - **지난 글 보기 및 수정/삭제**: 제목을 클릭하면 작성 일시와 본문 내용을 바로 읽을 수 있으며, [수정] 메뉴를 통해 내용 변경 및 저장 가능

6. **사진첩 (초경량 자동 압축 & 파이어베이스 1GB 저장 최적화)**
   - **초경량 자동 압축 탑재**: 스마트폰 고화질 원본 사진(5~10MB)을 업로드 즉시 클라이언트 캔버스 엔진으로 **가로세로 640px, WebP 품질 0.52로 약 30KB 수준(99% 용량 절약)**으로 가볍게 압축합니다.
   - **파이어베이스 1GB 용량 한도 대응**: 1장당 약 30KB로 저장되므로, 1GB 무료 용량 내에서 **25,000장 이상의 사진을 안전하게 보관**할 수 있습니다.
   - **실시간 용량 통계**: 압축 전후 용량 절약 수치 및 전체 사진의 서버 용량 사용률(%)을 실시간으로 안내합니다.
   - **사진 나눔 갤러리**: 업로드된 사진을 카드 그리드로 감상하고, `[🔍 크게 보기]` 모달 뷰어 및 비밀번호/관리자 삭제 기능을 제공합니다.

7. **질문과 답 (Q&A)**
   - **방문자 질문 등록**: 방문자 누구나 이름, 4자리 비밀번호, 제목, 질문 내용을 작성하여 질문을 남길 수 있습니다.
   - **답변 대기 / 답변 완료 상태 배지**: 답변 상태를 한눈에 알아볼 수 있도록 색상 배지를 제공합니다.
   - **관리자 답변 작성 (예성원 / 8797)**: 관리자로 로그인하면 각 질문에 `[💬 답변 작성 / 수정]` 버튼이 활성화되어 방문자의 질문에 답변을 남길 수 있습니다.
   - **서버 이용 최소화**: 질문과 답변은 가벼운 텍스트 JSON으로 저장되어 서버 용량을 거의 차지하지 않습니다 (1건당 약 0.5KB).

8. **사이트**

## 3. 파이어베이스(Firebase) 실시간 데이터베이스 & Vercel 배포

1. **파이어베이스 프로젝트 정보**:
   - 데이터베이스 주소: `https://mywork-f631b-default-rtdb.firebaseio.com`
   - 콘솔 주소: `https://console.firebase.google.com/u/0/project/mywork-f631b/database/mywork-f631b-default-rtdb/data`

2. **파이어베이스 보안 규칙(Rules) 설정 방법**:
   - Vercel 및 일반 웹 브라우저에서 출석, 글, 사진, Q&A를 자유롭게 읽고 쓸 수 있도록 파이어베이스 콘솔의 **[규칙(Rules)]** 탭에서 아래와 같이 설정하고 **[게시(Publish)]** 버튼을 눌러주세요:
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```

3. **Vercel 배포**:
   - Vercel에 코드를 업로드하면 별도의 백엔드 서버 없이도 브라우저가 파이어베이스 REST API를 통해 실시간으로 데이터를 주고받습니다.

## 5. 깃허브(GitHub) 업로드 및 무료 호스팅(GitHub Pages) 방법

1. GitHub에서 새 저장소(New repository)를 생성합니다.
2. 바탕화면 `[복지기술과제]` 폴더 내의 파일들을 해당 저장소에 업로드(Push)합니다.
3. 저장소의 **Settings** -> **Pages** 탭으로 이동합니다.
4. **Branch**를 `main` (또는 `master`)으로 선택하고 저장(Save)하면 무료 웹사이트 주소가 생성됩니다.
